# Metro Sports — redesign preview
Static, mobile-first preview of a redesign of metrosportsnh.com. **Not the official site.** Every page carries a preview banner and `noindex`.

- Pages: `index.html`, the 4 galleries, `apparel.html`, `accessories.html`, `brands.html`, `contact.html`, `team-store.html`, `bedford-hockey.html`, `order/`, `checkout/`
- Old URLs (`home.htm`, `contact us.htm`, …) redirect to the new pages.
- Edit points: `assets/pricing-config.js` (sample prices), `assets/payments-config.js` (demo/live), `assets/chat-kb.js` (chat answers).
- Images are the shop's own photos, re-encoded to WebP. Catalog PDFs link to the originals on metrosportsnh.com.
